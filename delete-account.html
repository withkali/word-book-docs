Me보카 계정 및 데이터 삭제

앱 이름: Me보카 · 개발자: ilak · 최종 개정일: 2026년 8월 19일

Me보카 계정과 그에 연결된 모든 데이터의 삭제를 요청하는 방법을 안내합니다. 아래 두 가지 방법 중 하나를 선택하시면 됩니다.

방법 1. 앱에서 직접 삭제 (즉시 처리)

앱이 설치돼 있다면 이 방법이 가장 빠릅니다. 요청 없이 즉시 삭제됩니다.

Android

  1. Me보카 앱 실행
  2. 화면 아래 나 탭 선택
  3. 맨 위에 있는 프로필 카드(닉네임과 이메일이 표시된 영역)를 탭
  4. 계정 삭제 선택 후 안내에 따라 확인

iOS

  1. Me보카 앱 실행
  2. 설정 → 계정
  3. 계정 삭제 선택 후 안내에 따라 확인

방법 2. 이메일로 삭제 요청 (앱 없이)

앱을 이미 삭제하셨거나 접속이 어려운 경우, 아래 주소로 요청해 주세요.

요청 주소: support@ilak.kr
메일 제목: Me보카 계정 삭제 요청
본문에 포함해 주실 내용: 로그인에 사용하신 계정의 이메일 주소

본인 확인을 위해 가입에 사용한 계정의 이메일 주소로 보내주시기를 권합니다. 다른 주소로 보내시는 경우 추가 확인을 요청할 수 있습니다.

요청을 접수하면 지체 없이 처리하며, 늦어도 30일 이내에 삭제를 완료하고 회신드립니다.

계정은 그대로 두고 학습 데이터만 삭제하기

계정을 삭제하지 않고 학습 데이터만 지우실 수도 있습니다. 등록한 단어와 학습 기록이 기기와 서버 양쪽에서 삭제되며, 계정과 설정은 그대로 유지됩니다.

  1. Me보카 앱 실행
  2. 화면 아래 나 탭 선택
  3. 데이터 항목의 모든 단어 삭제 선택
  4. 확인 창에서 삭제를 확정

단어를 하나씩 지우고 싶으시면 단어장에서 해당 단어를 개별 삭제하실 수 있습니다.

이 방법으로 처리가 어려운 경우 support@ilak.kr 로 요청해 주세요.

계정 삭제 시 삭제되는 데이터

계정을 삭제하면 아래 항목이 모두 영구 삭제됩니다.

구분항목
계정로그인 식별자, 닉네임, 연락처 이메일, 이메일 인증 기록
학습 데이터등록한 모든 단어와 뜻·예문, 학습 상태와 정답 기록, 일별 학습 활동, 학습 레벨(CEFR), 목표 설정
구독구독 상태 기록, Pro 권한 정보
기기 내 데이터앱을 삭제하면 기기에 저장된 사본도 함께 제거됩니다

일정 기간 보관되는 항목

  • 삭제 표시 기록(tombstone) — 여러 기기 간 삭제를 정확히 반영하기 위한 내부 기록으로, 개인을 식별할 수 있는 내용을 담지 않습니다. 90일 후 영구 파기됩니다.
  • 법령상 보존 의무가 있는 기록 — 전자상거래 등에서의 소비자보호에 관한 법률 등 관계 법령이 보존을 요구하는 결제·거래 기록은 해당 법정 기간 동안 보관 후 파기됩니다.

구독은 별도로 해지해야 합니다

계정을 삭제해도 스토어 구독은 자동으로 해지되지 않습니다. 구독 결제는 Google Play 또는 Apple App Store가 관리하기 때문입니다. 계정 삭제 전에 아래에서 구독을 해지해 주세요.
  • Android: Google Play 스토어 → 프로필 → 결제 및 정기 결제 → 정기 결제
  • iOS: 설정 → Apple 계정 → 구독
